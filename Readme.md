# FinSight Analytics

FinSight Analytics is a full-stack personal finance application that helps users track income, expenses, budgets, savings goals, and cash-flow trends.

## Overview

The platform gives users a clear view of their financial activity through an interactive dashboard. Users can record transactions, organize expenses by category, monitor budgets, and review financial trends.

This project demonstrates practical experience in full-stack software development, REST API design, database management, authentication, testing, and cloud-ready deployment.

## Features

- User registration and login
- Income and expense tracking
- Transaction categorization
- Monthly budget management
- Savings goal tracking
- Cash-flow forecasting
- Financial dashboard
- Interactive charts
- CSV transaction imports
- Responsive design
- RESTful API
- Docker support
- Automated testing
