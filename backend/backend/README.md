# Backend

The FinSight Analytics backend is built with Python and FastAPI.

## Planned Responsibilities

- User registration and authentication
- Transaction management
- Budget management
- Savings goals
- Financial reporting
- Cash-flow forecasting
- PostgreSQL database access
- API validation and error handling
- Automated testing

## Planned Technology

- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- Pydantic
- Pytest
- Docker
