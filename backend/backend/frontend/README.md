# Frontend

The FinSight Analytics frontend is planned as a responsive web application built with React and TypeScript.

## Planned Features

- User registration and login
- Financial dashboard
- Transaction management
- Budget tracking
- Savings goals
- Cash-flow charts
- CSV imports
- Responsive navigation

## Planned Technology

- React
- TypeScript
- Tailwind CSS
- Recharts
- Axios
- React Router
- Vite
